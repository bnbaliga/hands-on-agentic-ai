Agentic Short-Term Memory: Building Stateful Agents with LangGraph
1. Introduction
Short-term memory enables AI agents to retain and recall information across conversation turns. Without it, agents treat each message as isolated, losing context and forcing users to repeat themselves.

This lab demonstrates how to build a stateful agent using LangGraph's MemorySaver checkpointing, enabling multi-turn coherence, thread isolation, and efficient context management. We use Google Gemini as the LLM provider.

2. Problem Statement
Stateless AI systems lose context after each message. This creates:

Context Loss: Agents forget prior interactions
Token Waste: Developers manually pass full history with every request
Conversation Ceiling: Long chats exceed the LLM's context window
Solution: LangGraph's MemorySaver checkpoints automatically save and restore conversation state, enabling multi-turn coherence and thread isolation.

3. What You'll Build
A professional scheduling assistant (butler agent) that:

Remembers multi-turn conversations
Drafts emails, records responses, books restaurants
Maintains isolation between concurrent conversations
Uses Google Gemini as the LLM
4. Tech Stack
LLM: Google Gemini (gemini-3.5-flash)
Agent Framework: LangChain + LangGraph
Memory: MemorySaver (in-memory checkpointing)
Agent Type: ReAct (reasoning + acting)

On every turn the agent:

Loads the saved messages for the thread ID from MemorySaver.
Lets Gemini read them with the new message and either reply or call a tool.
Saves the updated messages back under the same thread ID, then returns the reply.
A different thread ID starts with an empty history, which is why conversations stay isolated.

Step 2: Initialize LLM and Memory
llm is the Gemini chat model, routed through the lab gateway with your key. memory is a MemorySaver, an in-memory checkpointer that saves each conversation's messages so the agent can recall them on the next turn.


from langchain_google_genai import ChatGoogleGenerativeAI
from langchain.agents import create_agent
from langgraph.checkpoint.memory import MemorySaver

# Create Gemini LLM instance
llm = ChatGoogleGenerativeAI(
    model="gemini-3.5-flash",
    api_key=GEMINI_API_KEY,
    base_url=ENDPOINT_URL,
    additional_headers={
        "Authorization": f"Bearer {GEMINI_API_KEY}",
        "api-key": GEMINI_API_KEY,
    },
    temperature=1,
    max_tokens=1024,
)
# Create memory checkpoint
memory = MemorySaver()
print(" Gemini LLM initialized.")
print(" MemorySaver checkpoint created.")
Step 3: Define Tools
Three plain Python functions act as the agent's tools: drafting an email, recording a friend's reply and booking a restaurant. The agent reads each docstring to decide which tool to call, and the tools only return text, so no real email or booking is made.



def draft_email(recipient_list: str, subject: str, body: str) -> str:

    """Draft an email to a list of friends requesting their availability."""

    return f"""Email drafted:

To: {recipient_list}

Subject: {subject}

Body: {body}

[Ready to send]"""

def record_response(friend_name: str, availability: str) -> str:

    """Record a friend's availability response."""

    return f"Recorded {friend_name}'s response: {availability}"

def book_restaurant(name: str, date: str, time: str, party_size: int) -> str:

    """Book a restaurant table."""

    return f"Restaurant '{name}' booked for {party_size} people on {date} at {time}"

print("Tools defined: draft_email, record_response, book_restaurant")
Step 4: Create the Scheduling Agent
The system prompt gives the butler its role, its step-by-step process and its constraints. create_agent then combines the model, the three tools, the prompt and checkpointer=memory, which is what gives the agent memory across turns.



system_prompt = """Role: Professional butler, organizing social events and dinners.

Your Process:

1. Understand the user's event details (who, when, where preferences).
2. Draft an email invitation to friends requesting their availability.
3. Once you receive availability confirmation, consolidate responses.
4. Draft a restaurant booking call script with confirmed details.
5. Book the restaurant with final details (date, time, party size).
6. Draft a final confirmation email to all friends with venue, date, and time.

Key Behaviors:
- Break complex tasks into distinct steps.
- Use tools to draft communications and confirmations.
- Always confirm details before booking.
- Maintain a professional and organized tone.

Constraints:
- Do NOT book without confirmation.
- Do NOT send emails without drafting first.
- Always show your work and explain each step."""

# Create ReAct agent with memory

agent = create_agent(
    model=llm,
    tools=[draft_email, record_response, book_restaurant],
    checkpointer=memory,
    system_prompt=system_prompt,
)

print(" Scheduling agent created with MemorySaver.")
Step 5: Set Up Thread and Configuration
A thread ID names one conversation, and the checkpointer saves every message under it. Passing the same config on each call tells the agent to continue that conversation instead of starting a new one.


thread_id = "butler_session_001"
config = {"configurable": {"thread_id": thread_id}}
print(f" Thread ID: {thread_id}")
print(" Configuration ready.")
Step 6: Define Message Formatter
The agent returns the whole message history, not just its last reply. This helper walks the history from the end and returns the latest AI message, so we can print only the agent's answer.


def format_conversation(result):
    """Extract AI response from agent result."""
    messages = result.get("messages", [])
    for msg in reversed(messages):
        if hasattr(msg, "__class__") and "AIMessage" in str(msg.__class__):
            return msg.content
    return "No response generated."

print(" Message formatter ready.")

9. Key Takeaways
Checkpointing: Each conversation's state is saved automatically and loaded on the next turn. Thread Isolation: Multiple concurrent conversations stay independent via unique thread IDs. Token Efficiency: Only relevant thread messages are sent to the LLM, not entire histories. Multi-turn Coherence: Agents can reason across many turns without losing context. Tool Integration: Tools work seamlessly with checkpointing for stateful workflows.
